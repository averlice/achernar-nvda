Achernar

Achernar is a dedicated NVDA speech synthesizer for a single Piper voice. It runs fully offline; the voice model, the espeak-ng runtime, and the synthesis engine all ship inside the add-on.

Settings

  • Rate, Rate boost, Pitch, and Volume: the usual NVDA speech controls.
  • Expressiveness: how much the voice varies its delivery. 50 keeps the voice exactly as trained; lower is flatter and steadier, higher is more varied.
  • Show advanced voice parameters: reveals Piper's own inference controls. Each is a percentage of the voice's trained value, where 50 is that value.

Advanced parameters

  • Noise scale (variability): Piper's noise_scale.
  • Noise W (phoneme length variation): Piper's noise_w.
  • Length scale (model pace): Piper's length_scale.

Notes

This add-on deliberately has no voice catalog, no downloads, no lexicon, and no automatic language switching. It always speaks with its one bundled voice.
